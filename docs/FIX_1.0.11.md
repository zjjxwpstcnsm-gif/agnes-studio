# 1.0.11：历史请求一键复制并生成

基于主干 `55f4e6a`（1.0.10），保留前台服务、WorkManager、熄屏恢复和固定后台版包名。

## 行为

- 图片页、视频页、队列每张任务卡新增「复制并生成」。一次点击直接入队，成功后显示「已加入队列」，1.5 秒内防止误连点。
- 从历史 `spec_json` 复制提示词、模型、尺寸、画幅、seed、高级 JSON 和完整素材列表（包括首尾帧、参考图/音频/视频及 start_seconds / require_audio）。不读取当前编辑器中的生成参数，也不清空草稿。
- 创建独立新任务：全新本地 ID、创建时间、执行次数及结果。即使原任务已完成、失败、取消或仍在处理，也不会复制远端 video_id、结果或错误；原记录和结果保留。
- 新任务仍受队列容量与持久的 60 秒滑动窗口限制。视频免费档 1 RPM，图片按原分辨率分桶；等待和后续重试继续由后台队列处理。
- 视频发送时检查素材链接有效期，距离过期不足 60 秒就使用本地原文件重新中转，刷新后的链接与过期时间写入新任务。未过期链接复用，不重复上传；排队或重启后会再次检查。
- 旧版有本地原文件、但缺失过期时间的 Uguu / Litterbox 链接保守重传。图片过期链接有本地原图时直接编码 Data URI，不经过中转。
- 未开启中转、原素材缺失或已知链接过期且没有本地原文件时，显示可操作错误，不静默丢掉参考图。用户手工提供且没有有效期信息的外部 URL 仍由服务端验证；没有保存过的原文件无法从失效 URL 恢复。
- 原「复制提示词」「重新排队」按钮继续保留；后者用于恢复同一任务，仍保留已有 video_id。
