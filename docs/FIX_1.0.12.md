# 1.0.12：删除生成历史及本机结果

在 1.0.11 的复制生成和后台队列能力上增加删除功能，包名与固定签名继续保持。

## 使用

- 图片页、视频页和队列里的完成、失败、已取消任务显示「删除记录」。确认后删除该条记录、调用日志及应用内保存的图片/视频结果。
- 队列顶部「清理」会列出本次待删除的历史记录数量，确认后批量执行。进行中的任务不会被删除，需先取消；确认期间刚完成的新任务不自动加入本次清理。
- 删除无法恢复。导入的参考素材保留，因此复制出的任务仍能使用原素材。系统分享后另存到相册/下载目录的副本及服务器上的文件不由此操作删除。
- 删除不要求 API Key，不发送远端删除请求，不改变已有调用间隔记录。

## 文件与并发

- 删除应用 generated 目录下以该任务 ID 命名的 PNG/JPG/WebP/MP4，覆盖成功结果和失败/取消留下的未登记下载残留。
- 不根据记录中的任意路径递归删除；外部路径、参考素材、其他任务的文件不会被误删。符号链接和异常目录拒绝删除，保留记录以便重试。
- 数据库会在删除前重新检查任务是否结束；重新排队后的任务会被跳过。文件删除失败时保留记录和调用日志，批量清理会继续处理其他选定记录并汇总失败数。
- 等待已取消任务的 HTTP 回调及文件写入结束后再清理，避免删除后仍有下载写入产生残留。执行器也会丢弃已经删除或已结束的旧调度对象。
- 批量清理捕获确认前的 ID 列表，删除期间禁用对应任务的再次生成/重试/删除操作。

## 验证

新增回归覆盖：图片和视频落盘文件删除、日志级联、数据库重开、失败/取消残留、参考素材与复制任务保留、调用间隔不被清空、活动/重启任务保护、文件错误保留记录、批量范围，以及取消下载与删除并发。UI 测试检查确认/取消、执行中隐藏删除入口。

CI 和最终安装包校验结果待本次构建后记录。未连接真机。

## 安装

`AgnesStudio-v1.0.12-background.apk`，版本 `1.0.12 (13)`，包名 `com.ppailab.agnesstudio.background`。
复用 1.0.10 / 1.0.11 后台版固定证书，支持覆盖安装并保留原数据；签名私钥不进入仓库和 CI。
