# 1.0.13：接入 Agnes 3.0 Flash

- 默认模型、聊天参数说明和连接测试统一为 `agnes-3.0-flash`，沿用 `POST /v1/chat/completions`。
- 数据库升级到 v4：已有 2.5 Flash 会话的模型改为 3.0，消息、其他参数、未知 JSON 字段与自定义模型保持。全局默认参数也做一次迁移，升级后手动选回旧模型不会再次被覆盖。
- Thinking 开关明确发送 true/false，覆盖高级 JSON 中冲突的设置；Tools 留空时真正移除工具定义和 tool_choice。
- 流式和非流式回复继续支持独立 Thinking、正文与工具调用卡片，工具结果可继续回填。
- 3.0 文档规定使用图片 URL；本地聊天图片复用公开素材中转开关，未开启时给出说明，绝不静默上传。上传结果在回调中持久保存，重试复用，过期后从原本地文件重传；没有本地副本的过期图片给出重新添加提示。
- 连接测试关闭 Thinking 并提供 32 Token 输出预算；仅 HTTP 200 且包含有效文本才提示连接成功。
- 保留 1.0.12 历史复制、删除和后台生成功能。图片、视频模型继续使用原模型。

## 验证

增加保存设置与数据库 v3 升级回归、真实 HTTP 客户端拦截测试（连接测试、SSE 与非流式、Thinking、工具回填）、图片中转开关和缓存过期回归。执行项目现有 Lint、单元/Robolectric 测试和 APK 构建；结果见对应 CI。模拟响应测试不代表已完成真实 Agnes 服务或 Android 真机验收。
